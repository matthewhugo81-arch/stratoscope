GloSea 60N/10hPa seasonal wind outlook.

Contains modified Copernicus Climate Change Service information (2026). UK Met Office GloSea6-GC5.1; CC BY 4.0.

https://cds.climate.copernicus.eu/datasets/seasonal-original-pressure-levels

Equal-weight lagged ensemble; two members from each of 25 daily starts. Aligned by valid date. Longitude means on the CDS 1-degree grid, linearly interpolated to 60N if required. Raw model output; no bias correction. Negative wind fraction is not a calibrated SSW probability.
